# Meridian assets

- `continuity.webp`: original interlocking-link sculpture created for this prototype. Geometry, projection, lighting and raster output are authored in `render-sculpture.py`; no third-party model or photograph is used.
- `instrument-sans.woff2`: Instrument Sans variable font, distributed under the SIL Open Font License. See `Instrument-Sans-LICENSE.txt`.
- `newsreader.woff2` and `newsreader-italic.woff2`: Newsreader variable fonts, distributed under the SIL Open Font License. See `Newsreader-LICENSE.txt`.
- Ambient lighting, technical rules, decorative graphics and pointer motion are implemented in the local CSS and JavaScript.

The sculpture is an editorial metaphor for continuity, not evidence of a completed transaction or portfolio holding. The rendering script is an optional authoring tool and is excluded from the published website.
