# Hyperboards Professional Frontpage Concepts

These two standalone homepage studies focus on institutional credibility, continuous business logic, and production-ready presentation. They do not replace or import the approved Astro homepage, and they do not modify the first-round concept studies.

1. `01-evergreen-partner/` — a calm, typography-led family-office presentation in evergreen, limestone, sage, and oxidized copper.
2. `02-cobalt-standard/` — a contemporary corporate system in cobalt, porcelain, graphite, mineral blue, and restrained terracotta.

Both use the same approved direct-buyer positioning, acquisition ranges, sectors, owner journey, and calls to action so the evaluation compares design rather than different claims. Permanent Equity, Chenmark, PPC, General Atlantic, and Alpine Investors informed the reference analysis; no competitor copy, identity, imagery, or track-record claims are reproduced.

Open either `index.html` directly or serve the repository root. Run `npm run qa:concepts:v2` for responsive, accessibility, interaction, and screenshot verification.
