# Hyperboards Frontpage Concept Studies

These are three standalone homepage design studies. They do not replace or import the approved Astro homepage.

1. `01-monumental-ledger/` — an editorial acquisition ledger built from typographic scale, ruled composition, and a registered seal.
2. `02-operators-atlas/` — an operating map built from coordinates, process routes, and a sector compass.
3. `03-quiet-cinema/` — a cinematic succession narrative built from light, scene cuts, and a stewardship filmstrip.

Open any folder's `index.html` directly, or serve the repository root and visit the folder path. Every prototype keeps the same approved direct-buyer positioning, acquisition ranges, sectors, and seller-first call to action so the comparison isolates design.
